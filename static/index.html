Team memory
Share what the brain knows about this project with your teammates. Write the share file saves this project's notes and the titles of unfinished work to .alt-brain.json in the project folder. Commit that file with the project; a teammate who opens the project in this app is offered the notes. Conversations and prompts are never included, and secrets are masked.
Terminal roles
A role is the standing job a terminal is given when it starts, for example Builder or Reviewer. Pick a terminal's role from the list in its bar. Built-in roles can be copied into a role of your own and changed there. A changed role reaches a terminal when it restarts.
Free models terminal
A special terminal that runs Claude Code on free AI providers. Use it when a Claude profile reaches its usage limit. Add a free API key for at least one provider; they are tried from top to bottom, and the next one takes over when one is limited. Keys are encrypted and stored only on this computer. Free models are weaker and slower than Claude.
